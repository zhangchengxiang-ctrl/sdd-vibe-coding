# Vibe Coding：本仓补充

> 通用流程由插件 Skill `vibe-coding` 管理。本文只记录本仓特有事实，不复制工作流合同。

## 开工

1. 读根 `AGENTS.md`；
2. 判定 Shape / Plan / Build / Verify / Repair / Diagnose / Incident；
3. Build / Repair 只读当前 `tasks/T-xxx.md` 与其显式依赖；
4. 按 Task 的 Workspace Strategy 选择 Local 或 Worktree。
