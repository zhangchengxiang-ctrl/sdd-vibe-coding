## 开工

1. 读根 `AGENTS.md`；
2. 检查当前目标所需能力是否 ready；
3. 使用自然语言理解用户结果，内部再判定工作轨；
4. Build / Repair 只读当前 Task 与其显式依赖；
5. 按 Task 的 Workspace Strategy 选择 Local 或 Worktree。
