## Workspace Strategy

```yaml
owner:
  kind: current-chat
  id: local

workspace:
  mode: local
  base_ref: "<host-default-branch>"
  base_sha: "<confirmed-sha>"
  branch: codex/<spec>-t-001
  setup: "<host-defined>"
  shared_resources: []
  claims: []

native:
  plan_item: null
  goal_id: null
  thread_id: null
  subagent_id: null

delivery:
  target: local-diff
  pr_base: "<host-default-branch>"
  merge_after: []
  merge_before: []
  integration_retest: required
```

`claims` 只列数据库、端口、账号、浏览器、部署槽位等外部资源。Task/file 所有权由单一
owner 与 Workspace 承担。原生能力不可用时保留 `current-chat`、`null` 绑定和
Local / CLI Git Worktree 回退。
