# 需求池

用户愿望、普通故障和体验反馈先记录在这里；生产事故另见
`docs/operations/incidents/`。入池 → Shape；实施以 `docs/specs/<id>/` 为准。

## 状态

| 状态 | 含义 |
|---|---|
| `draft` | 信息可能不完整 |
| `shaping` | 正在澄清产品切片 |
| `ready-for-plan` | 产品切片已确认，可进入 Plan |
| `planned` | 已有 Spec |
| `delivered` | 已交付 |
| `parked` | 暂不处理，附理由 |
