# 产品原则

1. **可重建** — `product/` + `specs/` + 代码为真源；实现以代码为准  
2. **可验证** — Requirement / Test 可测；有 UI 必须真实浏览器验收（方式见 `AGENTS.md`）  
3. **真源单一** — 关版 Test / Oracle 正文在 Spec；modules 只索引 `T-xxx`
4. **维护态诚实** — `accepted` 模块不重开全文；大改走新包或增量包  
5. **（宿主增补）** — 进程隔离、权限边界等写入本文件并链 system-map
