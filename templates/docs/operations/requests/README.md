# 跨团队请求单（Requests）

回答「找谁、要对方做什么、做没做」。**本页是总览；每张请求单的状态以其自身为准**，不在这里抄。

> 与 `handoff.md` 区分：那是会话与任务索引；这里是向别的团队 / 角色提的请求。

## 规范

1. **一个主题一个文件或目录**：单项用 `<YYYYMMDD>-<slug>.md`；多项需求用 `<YYYYMMDD>-<slug>/`（`README.md` 清单 + 每项一个文件）。模板：[`_template.md`](./_template.md)。
2. **必填头部**：找谁、来源（缺口 / Spec / 迭代）、要对方做什么、做完怎么验证、期限、状态。
3. **状态**用工作项词表（vibe-coding `references/states.md` §5）：`open → shaping → planned → done | dropped`；`dropped` 必须写 `reason:`，对方进度写 `note:`。
4. **回复记录**：对方的回复、决定、状态变化追加到单据底部，写日期与回复人；与正文冲突时以最新回复为准，并回头修正文。
5. **口径来自手写 SQL / 代码还原时**，标「待口径负责人确认」，定稿后补「已确认：谁 / 何时」。
6. **关闭**：已交付或不做的单据保留 30 天后移入归档，并从上表删除。
7. **不与缺口登记重复**：缺口登记记「问题是什么」，请求单记「谁欠谁一个回复」。
