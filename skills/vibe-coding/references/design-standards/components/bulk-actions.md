# Bulk actions（批量）

> 蒸馏自 taste-saas bulk-actions。用于 `page_kind: list`。

## 合同

1. **选择模型**：行首 checkbox；表头全选当前页（或明确「全选所有匹配」并二次确认）。  
2. **行动条**：有选中时，工具条筛选区可被 **行动条替换或并列**；显示已选数量。  
3. **主/危**：主批量行动一个实心；危险（删/禁用）需确认，写清数量与范围。  
4. **完成后**：清除选择或保留（写明）；toast 可带撤销则优先。  
5. **权限**：不可操作的行禁用勾选或提交时过滤并说明。

## 忌

- 批量无数量反馈  
- 危险批量一键无确认  
- 与行内主 CTA 视觉权混淆  

## 自检

- [ ] 选中数可见  
- [ ] 危险确认含范围  
- [ ] 与 list URL/筛选状态可共存
