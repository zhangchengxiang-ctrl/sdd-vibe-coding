# Consumer primitives（C 端组件处方）

> 按 `motif` 选骨架；尺度 → [../tokens/scale.md](../tokens/scale.md)。

## 共用

| 项 | 要求 |
|----|------|
| 主 CTA | 高度 ≥44（`control-lg`）；文案=下一动作 |
| 次要行动 | 视觉降级；不与主 CTA 同权 |
| 触控 | 可点目标 ≥24，推荐 44；`touch-action: manipulation` 按需 |
| 图标 | 14/16 两档；禁彩色瓷片装饰图标墙 |

## in-product

| motif | 主画布偏好 | 忌 |
|-------|------------|-----|
| feed | 信息流卡片、分页/无限滚动 | 后台表 |
| chat | 会话列 + 消息区 | 多列表格管理脸 |
| commerce | 商列/商详/购车/结算路径 | 运营密表当首页 |
| media | 播放器/内容为主 | 仪表盘 KPI 墙 |
| utility | 短任务表单/工具 | 无必要侧栏信息架构 |

- 列表项：标题 > 元数据；长文 truncate/`line-clamp`。  
- Sheet/底栏：手势与系统返回优先于纯 hover 菜单。

## growth（落地页）

| 项 | 具体 |
|----|------|
| 首屏 | 品牌 + 1 标题 + 1 短句 + CTA 组 + 1 主视觉 |
| 标题字号 | 用 `type-2xl` / `type-display` 封闭阶梯，禁半档 |
| 主 CTA | ≥44；可配一个文字链二次行动 |
| 间距 | 大段用 24/32/48；勿密表 8px 节奏铺整页 |
| 媒体 | 全幅或主导视觉平面；忌无叙事 inset 卡片英雄墙 |

定调（字体配对/主色/参考）未定 → 不写视觉实现。
