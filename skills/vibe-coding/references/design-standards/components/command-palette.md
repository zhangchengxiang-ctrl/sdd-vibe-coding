# Command palette（Cmd+K）

> 蒸馏自 taste-saas overlays-and-keyboard。`surface: product` 控制台默认应考虑；consumer 按需。

## 合同

- 全局：**Cmd+K 与 Ctrl+K** 双键。  
- 四段固定序：**Recent → Actions → Navigate → Search**（无则跳过空段，勿乱序）。  
- 搜索走服务端 `q` 或明确本地索引；展示加载与空。  
- 选中项 Enter 执行；Esc 关闭；箭头移动。  
- 打开时焦点在输入；关闭还原焦点。

## 视觉

- 顶锚定（类 Modal）；限高列表滚动。  
- 勿每开一次都长大动画（高频 → 可无动画，见 ai-tells 频率门）。

## 与导航

- Navigate 项须深链真实路由。  
- 勿用 Cmd+K 代替页面内筛选（列表筛选仍在 list 工具条）。

## 自检

- [ ] 双键；四段序  
- [ ] 键盘全可达  
- [ ] 高频无烦躁动画
