# Page: consumer（C 端页面型）

> 寄存器与硬忌在 [../surfaces/consumer.md](../surfaces/consumer.md)（**motif 表只在那边**）。  
> 本册只写**页面级**约束；`motif:` 与 `page_kind:` 等价。

## 通用

- 主 CTA ≥44；一屏一主任务。  
- 五态：空/载/错/成功/无权限（文案见 [../copy.md](../copy.md)）。  
- 禁运营密表壳；输出前扫 [../audit/ai-tells.md](../audit/ai-tells.md)。

## 页面级约束（按 motif）

### feed

- 分页或无限滚 + 明确加载更多；下拉刷新（移动）可选；保持位置锚点。  
- 卡片：封面/标题/元信息层级死。

### chat

- 桌面：会话列表 + 消息；移动：栈推。  
- 输入区固定底；发送明确；失败可重发；发送中/失败可见。

### commerce

| 子页 | 约束 |
|------|------|
| 列表/搜索 | 筛选项可懂；结果数；空态清筛选 |
| 商详 | 价格/主 CTA 首屏可见；图库一手势；规格选择器清晰 |
| 购物车 | 数量改、删、金额汇总静态可见 |
| 结算 | 步骤清晰；支付/地址错误 What/Why/Next；敏感信息勿悬停才见 |

### media

- 播放器为主；控件达触控尺寸；相关列表次级不抢播放。

### utility

- 短任务；少步；完成有明确结束态；视觉仍 C 端（非侧栏管理台）。

### growth（落地）

- 定调门 + 首屏预算 → **surfaces/consumer**。  
- 后续一节一职；证言/数据须可溯；CTA 贯穿。

## 权限与登录墙

- 未登录拦截：说明价值 + 登录/注册 CTA；勿空白 403。  
- 登录后回跳原任务深链。
