## 结构

1. **时间范围** → URL（`range`/`from`/`to`）。  
2. **KPI 行**：等高（如 h-28）；label + 大数 tabular-nums + **对比 delta**；可选 sparkline。  
3. **图卡**：同页锁定同一高度（h-56 或 h-72）；标题一行；tooltip 用主题色而非库默认白盒。  
4. **下钻**：点到 list/detail，目标写清。

## 硬约束

| 项 | 要求 |
|----|------|
| 主次 | 禁无主次四等 KPI；真对等才四等 |
| 对比 | 尽量环比/目标；孤立大数慎用 |
| 色 | 系列仅 `chart-*`；成败色不装饰「好看」 |
| 空/载 | **卡内**空与骨架；禁整页单转圈挡死 |
| 诚实 | 单位/口径/人群靠近图；长度编码从 0 基线（除非标明） |

## Chart 选型门（先故事再图）

写图前先回答：**比较 / 趋势 / 构成 / 关系 / 分布？** 再选类型；**禁止默认柱状图**。

| 故事 | 优先 | 慎用 |
|------|------|------|
| 类别对比 | bar（少类）/ table | 3D、装饰饼 |
| 时间趋势 | line / area | 类别轴乱当时间 |
| 构成（部分↔整体） | stacked bar 或少量 pie | 多扇区饼 |
| 关系/相关 | scatter | 假相关色编码 |
| 精确查数 | **表** 优先于图 | 只图无表 |

色不作为**唯一**通道（加位置/图案/标签）。无故事 → 先 KPI+表，勿堆图。
