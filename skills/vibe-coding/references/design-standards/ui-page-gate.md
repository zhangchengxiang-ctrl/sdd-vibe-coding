# UI Page Gate（有 UI 时的页面设计门控）

> 跨仓通则。新建 / 大改用户可见页面（或含表单的 Dialog / Sheet）时，在写业务 UI 代码前执行。  
> 宿主组件名、路由目录、列表 API → 读 `AGENTS.md` 与仓内实现手册。  
> 加载合同 → [README.md](./README.md)。好不好看 → [visual.md](./visual.md)；好不好用方法论见下文。

**硬门：** 禁止把后端字段 / 表结构直接平铺成 UI；先做产品判断与 IA，再探测资源，输出评审并等确认。

## 何时启用

- 新建路由页面、大改布局或主任务；
- 新增含表单的 Dialog / Sheet / Drawer；
- Spec / Shape 已确认有 UI Job，进入 Build 写页面之前。

trivial 文案 / 单点 CSS / 已知单控件 bug → 可跳过完整评审，仍遵守四态与主次不退化。

## 阶段一：五个产品问题 → 一句页面定位

不确定就问用户，别猜：

1. **谁在用？** 角色与熟练度  
2. **核心任务？** 用户 80% 时候来此要完成的一件事  
3. **频率与场景？** 高频工具页 vs 低频配置页（密度完全不同）  
4. **决策依赖什么信息？** 同屏必需 vs 可折叠 / 二级  
5. **失败与边界？** 首次空、无权限、加载慢、操作错  

浓缩成一句**页面定位**（谁 · 核心任务 · 频率）。后续布局服从这句话。

## 阶段二：信息架构决策（每条要有理由）

| 决策 | 要求 |
|------|------|
| 页面骨架 | 列表 / 详情 / 配置 / 表单 / dashboard — 按核心任务选；混任务则拆页或 Tab |
| 主次 | 唯一主任务占黄金位、路径最短；次要操作降级到行内 / 菜单 / 二级 |
| 渐进披露 | 默认只给完成主任务的必需信息；高级与低频折叠 |
| 信息密度 | 高频紧凑；低频宽松、强引导 |
| 操作路径 | 数清点击次数；能预填则预填；ID 类字段优先选择器，不默认手填 |

### 骨架速查

| 类型 | 核心任务 | 忌 |
|------|----------|----|
| 列表 / 管理 | 找一条、批量操作 | 用卡片墙代替表格 |
| 详情 | 看清一个实体 | 全字段一长列；关键状态埋中间 |
| 配置 | 偶尔改设置 | 无分组的开关堆；硬两列 |
| 表单 | 录入 / 修改 | 按库表顺序；一次铺几十字段 |
| Dashboard | 一眼掌握、发现异常 | 无对比的孤立数字；等大卡片墙 |

## 阶段三：探测现有资源（宿主路径）

按 `AGENTS.md` 与现有代码探测：相关 API、可复用选择器 / 表格 / 布局、相似页面。

表单字段来源：

| 类型 | 做法 |
|------|------|
| ID / 外键 | 有列表 API → 选择器；无才手填并标明原因 |
| 枚举 | 用后端 / 共享常量，不散落魔法字符串 |
| 关联实体 | 查询 + 搜索选择 |
| 自由文本 | 才用普通 Input |

## 阶段四：设计评审（确认前不写 UI 业务码）

输出后**停下等确认**：

```text
### 页面设计评审：[页面名]
页面定位：…
设计决策：骨架 / 主次 / 披露 / 密度（各带理由）
信息架构：区块 + 数据来源（示意即可）
字段清单：字段 · 组件类型 · 数据来源 · 必填
主干流程：进入 → 操作 → 成功/失败反馈（点数点击）
四态：首次空 / 筛选无结果 / 加载 / 错误·无权限
与其他页关系：来源 → 本页 → 去向
待确认问题：…
```

## 阶段五：实现（确认后）

1. 视觉服从 [visual.md](./visual.md)（先灰度后上色、一屏主 CTA、四态）。  
2. 栈与组件服从宿主实现手册 / `AGENTS.md`。  
3. 异步区必有加载与错误反馈；列表必有空态 CTA。

## 阶段六：验收

用真实浏览器通道走通主干 Job（见 [browser-verify](../../../testing/references/browser-verify.md)）。  
易用性自检（目标 ≥ 8/10，违反一项扣 1）：

- [ ] 页面定位清晰且布局服从它  
- [ ] 骨架正确，非字段平铺  
- [ ] 主任务在黄金位、路径最短  
- [ ] 渐进披露与密度匹配频率  
- [ ] 决策信息同屏；能预填已预填  
- [ ] 四态齐全  
- [ ] 操作有反馈；危险确认、常规不无谓打断  
- [ ] 无「接口 / 表结构直接映射成 UI」痕迹  

视觉自检 → [visual.md](./visual.md) §自检。
