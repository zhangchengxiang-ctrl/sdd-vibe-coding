# Visual（视觉与呈现默认）

> 社区锚点：WCAG 2.2 AA 可执行子集；信息层级与状态可见性的通用实践。  
> **不是**品牌皮肤或完整 Material / HIG。宿主设计系统与品牌写在 `AGENTS.md` 或产品文档。  
> 加载合同 → [README.md](./README.md)。页面施工前门控 → [ui-page-gate.md](./ui-page-gate.md)。

## 1. 一屏一主任务

- 每个关键视图有且仅有一个主行动或主信息目标；
- 次要操作降级（次按钮、菜单、后续步骤），避免与主 CTA 同等视觉权重；
- 首屏不堆统计条、元数据行、多重营销块抢主任务（营销落地页服从产品包，不服从「仪表盘默认」）。

## 2. 先灰度，后上色

写界面时先用**大小 / 字重 / 对比 / 留白**拉开层级，最后才上色。  
颜色用于**状态、唯一主 CTA、品牌强调**；不用颜色区分同级信息。

- 主信息：更大、更重、更高对比；次信息弱化；
- 关掉颜色后，主次仍应可读；
- 低饱和优先；避免默认蓝堆砌、高饱和「AI 紫」、纯黑/纯白硬编码（有设计 token 时用 token）。

## 3. 信息层级

| 层级 | 用途 |
|---|---|
| 一级 | 品牌或页面标题、当前 Job 名称 |
| 二级 | 支撑说明（一句内） |
| 三级 | 列表、表格、辅助元数据 |

任务名与主信息层级优先于装饰性大标题；列表项标题 > 元数据。

数据 / Dashboard 页：最重要 KPI 在左上；指标尽量带对比基准；一屏控件宜少而清晰；「逐条查找」用表格，不用等大卡片墙。

## 4. 间距、排版与深度

- 间距用宿主设计尺度（常见 4px 网格）；区块之间敢留白；分组优先留白，其次细分割线；
- 字号来自模块化尺度；正文行宽约 ≤ 65 字；技术值可用等宽；
- 边框 / 阴影「耳语」级；暗色界面优选用边框分层而非重阴影；圆角内外同心。

## 5. 状态必须可见

每个会异步或可失败的表面，至少区分并设计：

| 状态 | 最低要求 |
|---|---|
| 空（首次） | 说明为何空 + 可行下一步 CTA |
| 筛选无结果 | 说明 + 清除筛选入口 |
| 加载 | 可感知进度或骨架；极短延迟可不闪 |
| 错误 | 人话原因 + 可行下一步（对齐 UX H9） |
| 成功 / 完成 | 用户能确认 Job 结果与影响范围 |
| 无权限 | 与「空」区分；说明谁可申请或如何切换角色 |

## 6. 数据墨水与图表

- 去掉装饰性 3D、重网格；系列色只区分必要类别；
- 状态不只靠颜色（配文案 / 图标）；
- 徽章与标签保持低饱和，避免高饱和色块墙。

## 7. 动效克制

- 尊重 `prefers-reduced-motion`；无不必要闪烁；
- 优先短时、非匀速、只动 transform / opacity；
- 微交互服务反馈，不抢主任务。

## 8. 避免「AI 默认味」

- 默认系统无衬线 + 默认蓝 + 等大卡片墙；
- emoji 当图标；落地页式渐变紫 / 大圆角 / 重阴影塞进产品后台；
- 假数据 / lorem 撑场面。  
内容真实、密度专业、克制有序。

## 9. WCAG 2.2 AA 可执行子集（有 UI 时默认）

宿主可在 AGENTS 声明更高或豁免项；未声明则按下列验收：

| 项 | 底线 |
|---|---|
| 文本对比度 | 正常文本 ≥ 4.5:1；大文本 ≥ 3:1 |
| UI 组件对比度 | 控件与相邻色 ≥ 3:1 |
| 触控目标 | 可点击目标 ≥ 24×24 CSS px（推荐 44×44） |
| 键盘 | 全部交互可达；焦点顺序合乎阅读序 |
| 焦点可见 | 每个可交互元素有可见 focus 指示 |
| 语义 | 标题层级、按钮/链接角色正确；表单有 label |
| 图片 | 信息性图片有替代文本；装饰性 `alt=""` |
| 色觉 | 不只用颜色传达状态（配图标/文案） |
| 动效 | 尊重 `prefers-reduced-motion`；无不必要闪烁 |

法律/区域强制更高标准时，以宿主 AGENTS 与合规要求为准。

## 10. 与宿主设计系统

- 已有 token / 组件库 → **优先复用**现有间距/色板；
- 无设计系统 → 本册底线 + 本仓库已有页面模式；
- 品牌色、字体、插画风格 → 只写 AGENTS 或产品包，不写进本插件默认。

## 11. 自检（有 UI；目标 ≥ 8/10，违反一项扣 1）

- [ ] 关掉颜色后层级仍清晰  
- [ ] 颜色主要用于状态 / CTA / 品牌  
- [ ] 间距与字号有尺度；区块留白够用  
- [ ] 数据页主信息在黄金位；非必要不卡片墙  
- [ ] 深度克制；四态已设计  
- [ ] 动效克制并尊重 reduced-motion  
- [ ] 无「AI 默认味」  
- [ ] 可访问性底线无故意违反；豁免已写入 AGENTS 或 Spec  
- [ ] 未平行发明第二套视觉语言  

## 12. Verify

视觉问题单独不足以关版失败，**除非**导致 Job 失败、严重度 4，或违反已写入 Spec / AGENTS 的可访问性合同。走查时与 [ux.md](./ux.md) 一并记录。
