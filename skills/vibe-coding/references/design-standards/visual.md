# Visual（视觉与呈现默认）

> 社区锚点：WCAG 2.2 AA 可执行子集；信息层级与状态可见性的通用实践。  
> **不是**品牌皮肤或完整 Material / HIG。宿主设计系统与品牌写在 `AGENTS.md` 或产品文档。  
> 加载合同 → [README.md](./README.md)。

## 1. 一屏一主任务

- 每个关键视图有且仅有一个主行动或主信息目标；
- 次要操作降级（次按钮、菜单、后续步骤），避免与主 CTA 同等视觉权重；
- 首屏不堆统计条、元数据行、多重营销块抢主任务（营销落地页服从产品包，不服从「仪表盘默认」）。

## 2. 信息层级

| 层级 | 用途 |
|---|---|
| 一级 | 品牌或页面标题、当前 Job 名称 |
| 二级 | 支撑说明（一句内） |
| 三级 | 列表、表格、辅助元数据 |

任务名与主信息层级优先于装饰性大标题；列表项标题 > 元数据。

## 3. 状态必须可见

每个会异步或可失败的表面，至少区分并设计：

| 状态 | 最低要求 |
|---|---|
| 空 | 说明为何空 + 一个可行下一步（若有） |
| 加载 | 可感知进度或骨架；不假装已有数据 |
| 错误 | 人话原因 + 可行下一步（对齐 UX H9） |
| 成功 / 完成 | 用户能确认 Job 结果与影响范围 |
| 无权限 | 与「空」区分；说明谁可申请或如何切换角色 |

## 4. WCAG 2.2 AA 可执行子集（有 UI 时默认）

宿主可在 AGENTS 声明更高或豁免项；未声明则按下列验收：

| 项 | 底线 |
|---|---|
| 文本对比度 | 正常文本 ≥ 4.5:1；大文本 ≥ 3:1 |
| UI 组件对比度 | 控件与相邻色 ≥ 3:1 |
| 触控目标 | 可点击目标 ≥ 24×24 CSS px（推荐 44×44） |
| 键盘 | 全部交互可达；焦点顺序合乎阅读序 |
| 焦点可见 | 每个可交互元素有可见 focus 指示 |
| 语义 | 标题层级、按钮/链接角色正确；表单有 label |
| 图片 | 信息性图片有替代文本；装饰性 `alt=""` |
| 色觉 | 不只用颜色传达状态（配图标/文案） |
| 动效 | 尊重 `prefers-reduced-motion`；无不必要闪烁 |

法律/区域强制更高标准时，以宿主 AGENTS 与合规要求为准。

## 5. 与宿主设计系统

- 已有 token / 组件库 → **优先复用**现有间距/色板；
- 无设计系统 → 本册底线 + 本仓库已有页面模式；
- 品牌色、字体、插画风格 → 只写 AGENTS 或产品包，不写进本插件默认。

## 6. Shape / Plan 自检（有 UI 时）

- [ ] 主 CTA / 主信息层级清晰  
- [ ] 空 / 加载 / 错 / 成功 / 无权限 五种状态有意图（可在 03 或 plan 简述）  
- [ ] 可访问性底线无已知故意违反；豁免须写入 AGENTS 或 Spec  
- [ ] 不引入与现有表面冲突的第三套视觉语言  

## 7. Verify

视觉问题单独不足以关版失败，**除非**导致 Job 失败、严重度 4，或违反已写入 Spec / AGENTS 的可访问性合同。走查时与 [ux.md](./ux.md) 一并记录。
